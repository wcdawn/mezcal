# Microreactor

This will be the program to model microreactors for my Ph.D. dissertation.
This project is in association with Oak Ridge National Laboratory (ORNL) and the Exascale Computing Project.

# Building
From a `bash` shell, run
```
$ ./update_and_rebuild.sh -j<NPROC>
```
to update the dependencies and recompile with `<NPROC>` processors.
